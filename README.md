# BestTrip — анимации блоков

Живые демо анимаций для блоков сайта BestTrip. Сайт: https://pugachoveo.github.io/besttrip-animations/

Репозиторий публичный: сюда кладём только демо, без кода основного сайта и без закрытых данных.

## Как добавить демо

1. Создать папку с понятным названием, например `cases-carousel/`.
2. Положить в неё `index.html` — один самодостаточный файл (стили, скрипты и картинки внутри или рядом в той же папке).
3. Добавить карточку со ссылкой в корневой `index.html`.
4. Закоммитить и запушить в `main` — через минуту демо будет по адресу `https://pugachoveo.github.io/besttrip-animations/<папка>/`.
