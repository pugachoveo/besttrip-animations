# BestTrip — анимации блоков

Живые демо анимаций для блоков сайта BestTrip. Сайт: https://pugachoveo.github.io/besttrip-animations/

Репозиторий публичный: сюда кладём только демо, без кода основного сайта и без закрытых данных.

## Как добавить демо

1. Создать папку с понятным названием, например `cases-carousel/`.
2. Положить в неё `index.html` — один самодостаточный файл (стили, скрипты и картинки внутри или рядом в той же папке).
3. Подключить хедер: `<script src="../assets/header.js" defer></script>` в `<head>`.
4. Добавить ссылку в меню — массив `NAV` в `assets/header.js` (раздел и пункт), и карточку в корневой `index.html`.
5. Закоммитить и запушить в `main` — через минуту демо будет по адресу `https://pugachoveo.github.io/besttrip-animations/<папка>/`.

## Демо

- [Собираем конференцию целиком](https://pugachoveo.github.io/besttrip-animations/conference-accordion/) — аккордеон, пункты раскрываются независимо, карточка с иллюстрацией едет при прокрутке.

## Хедер

`assets/header.js` + `assets/header.css` — утверждённый хедер BestTrip (десктоп от 1440, компактный с бургером ниже). В меню только разделы, для которых есть демо.
